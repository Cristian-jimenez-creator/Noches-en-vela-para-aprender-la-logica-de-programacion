# Noches-en-vela-para-aprender-la-logica-de-programacion
Un espacio para documentar mi camino aprendiendo la lógica de programación desde cero. Estoy convencido de que dominar la lógica es el cimiento fundamental de todo desarrollo de software: el pilar que permite ser un verdadero ingeniero. Este proyecto recopila mis desvelos, notas, ejercicios y avances en el arte de pensar como programador.


Desde Hace mucho tiempo he sabido de la existencia de sistemas. pero nunca le di la suficiente atención como debia de haberlo hecho es tan poco tiempo que le he dedicado que aun con grandes oportunidades que he tenido no las he sabido aprobechar
